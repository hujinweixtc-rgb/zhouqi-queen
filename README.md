# 周期女王文章目录（水墨松鹤版）

把公众号「**周期女王**」的历史文章做成了一个**单文件在线目录**：189 篇内容（长文 + 午评 + 札记）配上每篇发文当天的市场数据快照，水墨松鹤风排版，手机电脑都能看。

**在线阅读**：GitHub Pages 开启后访问 → `https://hujinweixtc-rgb.github.io/zhouqi-queen/`

## 怎么用

- **打开即用**：单文件网页，无需注册登录，数据全部存在你自己的浏览器里
- **搜索**：顶部搜索框支持标题、正文、出处关键词；直接输 `10-23` 或 `1.23` 也能按日期搜出对应文章
- **排序**：右上「⇅ 最新在上」一键翻转新旧顺序
- **读原文**：每篇卡片底部「阅读原文 →」跳转公众号原文
- **已读打勾**：每篇文章右侧有个小圆圈，读过的点一下变绿色 ✓（再点取消），刷新和下次打开都会记住，方便追更时知道哪些看过了
